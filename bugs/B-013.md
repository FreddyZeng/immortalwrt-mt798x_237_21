# B-013: 限速设备在命中高优先级规则后 Q31/Q63 最终覆盖缺失

<!-- BID: B-013 | FID: F-QOS01 | CID: C-FQOS01-10 -->

## 症状

限速设备（`eqos add` Branch 2：up/dl > 0）在以下情况下会旁路 Q31/Q63 限速队列：
- 设备 IP 在 109.x 子网内（命中 FORWARD `DSCP --set-dscp 1/33` 游戏规则）
- 设备 IP 在静态 VIP 范围 110-119.10-39 内（命中 FORWARD `DSCP --set-dscp 0/32` VIP 规则）

旁路后流量进入 SP VIP 队列或游戏队列，**硬件限速器失效**，限速配置无意义。

## 根因

`eqos add` Branch 2 仅在 `eqos` chain 头部插入 DSCP=31/63 规则（`-I eqos 1`）。  
但 FORWARD 链处理顺序：  
1. 全局 fallback `DSCP 2/34` → eqos chain → 游戏规则 → 静态 VIP u32 规则  
2. 所有 DSCP 规则非终止（不 ACCEPT），最后一条匹配胜出  
3. eqos chain 中的 DSCP=31/63 规则被后续的游戏/VIP 规则覆盖 → 限速失效

## 修复

在 `eqos add` Branch 2 中，额外将 DSCP=31/63 规则追加到 **FORWARD 链末尾**（`-A FORWARD`），  
确保在游戏/VIP 规则之后触发，最终 DSCP 胜出：

```sh
iptables -t mangle -A FORWARD -s "$ip" -j DSCP --set-dscp 31
iptables -t mangle -A FORWARD -d "$ip" -j DSCP --set-dscp 63
```

使用 `/tmp/rl_forward_ips` 持久化记录限速 IP，保证 stop/start 和 hotplug 时幂等清理。  
清理函数：`cleanup_recorded_ipv4_forward_rules` + `cleanup_ipv4_forward_device_rules`。
