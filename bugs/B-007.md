# B-007: mtk_eth_soc.c mark leak — CPU TX 路径 mark 误当 qid

<!-- BID: B-007 | FID: F-QOS01 | CID: C-FQOS01-04 -->

## 症状
CPU 生成的本地流量（如 DNS 响应、ICMP）在 CPU TX 路径中，
skb->mark 的语义与 HNAT 期待的 qid 语义不匹配，
导致部分 CPU 发出的包意外进入高优先级队列。

## 根因
mtk_eth_soc.c CPU TX 路径将 skb->mark 低位当 qid 写入硬件，
而 skb->mark 在此时可能包含 mwan3 路由标记或其他非 QoS 语义值。

## 修复
CPU TX 路径添加 IS_HQOS_MODE 守卫，并对 skb->mark 做范围检查，
确保只有合法 qid 范围（0-63）才写入硬件队列字段。
